# Perfectman Examples

## Folders

- [`simulations/`](simulations/) — runnable simulation config examples.
- [`presets/`](presets/) — casts and scenes the web runner offers as starting points.
- [`personas/compiled/`](personas/compiled/) — an example character file, loaded with `agent.personaFile`.
- [`video/`](video/) — saved stories for `pnpm video`.

Characters are fictional. Do not model real people.
