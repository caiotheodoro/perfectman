# Video assets

The composition reuses the Perfectman demo's white and violet board and SVG
agents. Emotion expressions are illustrations of recorded values or authored
cues. They are not new simulation results.

`tap.wav` is a 0.16-second cut from the original, synthesized Perfectman demo
sound track. It contains no borrowed recording. The converter uses it as a
quiet message cue. The CSS and timeline source are part of this repository.

The converter copies DM Sans from the pinned font package and includes its
SIL Open Font License in each output project. GSAP comes from its pinned
package; its license link remains in the distributed file header. The logo
comes from `docs/assets/readme-logo.png`.
